# Widgets could be listed by creation date

## Context and problem statement

`listWidgets` sorts by name. Some callers would rather see the newest widget first. It has not been decided whether the library should offer that, or leave it to the caller.

## Decision

Not decided. This record is proposed and does not bind: the gates ignore it until it is accepted.

## Consequences

Until it is accepted, a request to sort widgets in another order is planned like any other request.
